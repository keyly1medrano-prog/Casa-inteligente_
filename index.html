PROYECTO DE ROBÓTICA

CASA INTELIGENTE

Una casa controlada por una red web es un proyecto tecnológico que integra electrónica, programación y robótica para crear un hogar capaz de responder a diferentes condiciones del entorno.

Mediante una tarjeta Arduino, sensores y dispositivos electrónicos, se pueden detectar movimientos, medir condiciones ambientales y activar luces u otros elementos. Su finalidad es demostrar cómo la tecnología puede facilitar actividades cotidianas y ayudar a crear espacios más cómodos, prácticos y eficientes.

¿En qué consiste el proyecto?

Una propuesta educativa para conocer cómo trabajan juntos los circuitos electrónicos, los sensores y la programación.

Descripción general

NEXUS es una maqueta de casa inteligente diseñada para demostrar cómo se pueden automatizar algunas funciones de una vivienda utilizando componentes electrónicos.

El sistema utiliza una tarjeta Arduino como unidad de control. Los sensores recopilan información del entorno y la tarjeta procesa esas señales para ejecutar acciones programadas, como encender una luz o responder ante un movimiento.

La página web presenta el proyecto, explica sus componentes, documenta los avances y reúne archivos, fotografías y videos. Para controlar la casa directamente desde el navegador, también debe implementarse un sistema de comunicación entre la web y los componentes electrónicos.

¿Qué se busca lograr?

Automatización Realizar determinadas acciones a partir de señales de los sensores.
Monitoreo Observar condiciones detectadas por los dispositivos electrónicos.
Control tecnológico Comprender cómo se pueden controlar dispositivos mediante sistemas electrónicos y digitales.
Aprendizaje práctico Aplicar conocimientos de programación, circuitos, robótica y diseño web.

Objetivos del proyecto

Propósitos que orientan el diseño y la construcción de la casa inteligente.

01

Objetivo general

Diseñar una maqueta de casa inteligente mediante Arduino, sensores y dispositivos electrónicos para la automatización básica del hogar.

02

Objetivo tecnológico

Diseñar un sistema tecnológico mediante una tarjeta Arduino y componentes electrónicos para la automatización del hogar.

03

Objetivo educativo

Diseñar actividades prácticas relacionadas con la robótica y el desarrollo web para el aprendizaje tecnológico.

Etapas del proyecto

El proyecto se organiza en etapas para avanzar desde la idea inicial hasta las pruebas y la presentación final.

01

Investigación y planificación

Se investiga qué es una casa inteligente, cómo funciona la domótica y qué tareas pueden automatizarse. Después se definen las funciones de la maqueta, los materiales necesarios y las responsabilidades de cada integrante.

02

Diseño de la casa

Se diseña la estructura de la vivienda y se decide dónde estarán las habitaciones, luces, sensores y dispositivos de control. También se organiza el espacio para instalar los componentes de forma ordenada y segura.

03

Selección de componentes

Se identifican los materiales necesarios, como la tarjeta Arduino, cables, resistencias, LED, protoboards y sensores. Se estudia la función de cada elemento para elegir los componentes apropiados.

04

Montaje de los circuitos

Se conectan los componentes en las protoboards siguiendo un esquema eléctrico. Se revisan las conexiones antes de alimentar el circuito para evitar errores y proteger los dispositivos.

05

Programación de Arduino

Se escribe el código que permite a la tarjeta leer las señales de los sensores y controlar las salidas. Se programan condiciones para encender luces o responder al movimiento, y se corrigen los errores.

06

Integración de los sensores

Se incorporan los sensores seleccionados y se comprueba qué información proporciona cada uno. Por ejemplo, el sensor PIR detecta movimiento y un sensor de humedad mide la humedad según su tipo.

07

Desarrollo de la página web

Se construye una página para presentar el proyecto, explicar su funcionamiento, mostrar los componentes, documentar las etapas y reunir imágenes, videos y archivos PDF. La conexión con Arduino requiere implementar también la comunicación correspondiente.

08

Pruebas de funcionamiento

Se prueba cada componente por separado y después se verifica el sistema completo. Se comprueba la respuesta de los sensores, el funcionamiento de los LED y la estabilidad de los circuitos.

09

Construcción y acabado

Se prepara la estructura física de la vivienda y se distribuyen los componentes en sus lugares. Se organiza el cableado y se identifican las partes principales para facilitar la demostración.

10

Documentación y presentación

Se recopilan fotografías, explicaciones, esquemas, código y resultados de las pruebas. Se organizan los documentos y se prepara una presentación para explicar los objetivos, materiales y resultados.

Componentes del sistema

Materiales electrónicos que pueden utilizarse en la construcción y programación de la casa inteligente.

Tarjeta Arduino

Es la unidad de control del circuito. Ejecuta el programa, recibe las señales de los sensores y controla las salidas.

Cables de conexión

Permiten unir los componentes electrónicos con Arduino y las protoboards para formar los circuitos.

Cable para Arduino

Se utiliza para conectar la tarjeta a una computadora compatible y cargar el programa.

LED

Son luces electrónicas que pueden representar la iluminación de una vivienda o indicar funciones activas.

Resistencias

Ayudan a limitar la corriente y proteger componentes como los LED cuando se elige el valor adecuado.

Dos protoboards mini

Permiten montar y probar circuitos sin soldar los componentes, facilitando las modificaciones.

Sensor analógico

Puede entregar una señal variable que Arduino interpreta para medir una condición, según el sensor utilizado.

Sensor PIR

Detecta cambios en la radiación infrarroja asociados con el movimiento dentro de su campo de detección.

Sensor de infrarrojos

Puede utilizarse para detectar objetos cercanos o cambios en la señal infrarroja, según el modelo.

Sensor de humedad

Permite medir la humedad del suelo o del ambiente, dependiendo del tipo de sensor.

Pantalla I2C

es un módulo que permite conectar una pantalla LCD a Arduino utilizando solo dos cables de comunicación: SDA y SCL. Facilita mostrar textos y datos con menos conexiones.

Fuente de alimentación

Proporciona la energía necesaria para el circuito. El voltaje y la corriente deben ser adecuados.

Estructura de la maqueta

Es la parte física de la casa y sirve para ubicar los componentes y representar una vivienda inteligente.
